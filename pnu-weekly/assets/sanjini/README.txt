산지니 이미지
=============

부산대 제공 원본에서 잘라낸 자산입니다. (프로젝트 루트의 '산지니 케릭터' 폴더가 원본)
잘라내는 스크립트는 tools/cut-assets.py 에 있습니다.

[표정 — 위험 등급]
  happy.png   기쁨   → Tier 1 관심
  base.png    기본   → Tier 2 주의
  tense.png   긴장   → Tier 3 경계 · 지도 로딩 실패
  angry.png   화남   → Tier 4 위기
  sad.png     슬픔   → 표본 부족 · 데이터 없음

[전신 — 섹션 성격]
  grad.png      졸업모   → 상단 공지 · 리포트 읽는 법
  question.png  물음표   → 향후 주시 포인트 · 취약점 진단 · 빈 상태
  idea.png      전구     → 모니터링 권고

모두 256x256 투명 PNG 입니다.
'반함' 표정은 이 보고서에 맞는 자리가 없어 잘라내지 않았습니다.

이미지를 교체하려면 같은 이름으로 덮어쓰고 `node build.mjs && node daily.mjs` 를 실행하세요.
